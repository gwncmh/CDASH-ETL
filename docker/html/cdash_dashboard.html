Kepler.gl – Crime Hotspot Explorer
⬇ crimes.geojson ⬇ forecast.geojson ↗ Mở Kepler.gl
⚙ Hướng dẫn tích hợp Looker Studio & Kepler.gl
1
Tạo báo cáo Looker Studio
Vào lookerstudio.google.com → Create Report → chọn connector BigQuery → dataset cdash_warehouse → bảng enriched_crime_data.
2
Tạo trang dự báo trong cùng report
Trong Looker Studio: nhấn + để thêm page mới → kết nối bảng prediction_results → tạo bảng top rủi ro, biểu đồ xác suất theo H3.
3
Lấy embed URL từng trang
File → Embed report → bật Enable embedding → copy URL dạng .../embed/reporting/{ID}/page/{PAGE_ID}. Mỗi trang có PAGE_ID khác nhau.
4
Dán URL vào file HTML này
Tìm hai thẻ iframe trong page-overview và page-hotspot, thay thuộc tính src bằng URL tương ứng.
5
Export dữ liệu cho Kepler.gl
Chạy POST /export/crimes trên exporter service để tạo file crimes.geojson. Hoặc query thẳng BigQuery → Save results → GCS.
6
Cấu hình và export Kepler.gl
Mở kepler.gl/demo → Add Data → tải crimes.geojson → cấu hình H3 Layer + Heatmap → Share → Export Map → lưu file kepler_export.html.
7
Host Kepler export
Đặt kepler_export.html cùng thư mục với dashboard này, hoặc host lên GitHub Pages rồi cập nhật src của iframe trong page-map.
8
Kiểm tra pipeline Airflow
Truy cập http://localhost:8080 → bật DAG crime_analytics_pipeline → trigger thủ công lần đầu. Dashboard sẽ tự cập nhật theo lịch hàng ngày.
