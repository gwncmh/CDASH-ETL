⚙ Hướng dẫn tích hợp Looker Studio & Kepler.gl
1
Tạo báo cáo Looker Studio
Vào lookerstudio.google.com → Create Report → chọn connector BigQuery → dataset cdash_warehouse → bảng enriched_crime_data.
2
Lấy embed URL
Trong Looker Studio: File → Embed report → bật Enable embedding → copy URL dạng https://lookerstudio.google.com/embed/reporting/{ID}/page/{PAGE}.
3
Dán vào file HTML này
Tìm comment <!-- KHI CÓ DỮ LIỆU --> trong trang UC1 và UC3, thay khối looker-placeholder bằng thẻ <iframe class="looker-iframe" src="…">.
4
Export dữ liệu cho Kepler.gl
Chạy query BigQuery xuất enriched_crime_data → Save to GCS → script auto_exporter.py sẽ tạo file enriched_crime_data.geojson vào bucket.
5
Tải GeoJSON vào Kepler.gl
Mở kepler.gl/demo → Add Data → tải file .geojson. Cấu hình H3 Layer + Heatmap. Save config JSON để tái sử dụng.
6
Embed Kepler hoặc dùng GitHub Pages
Export HTML từ Kepler (Share → Export Map) → host trên GitHub Pages → embed <iframe src="./kepler_export.html" style="height:620px"> vào trang UC2.
